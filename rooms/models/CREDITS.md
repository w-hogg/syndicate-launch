# Model credits

The furniture in Lime Street Rooms comes from **KayKit: Furniture Bits 1.0** by Kay Lousberg ([kaylousberg.com](https://www.kaylousberg.com)), from [github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0](https://github.com/KayKit-Game-Assets/KayKit-Furniture-Bits-1.0).

The pack is licensed under **Creative Commons Zero (CC0)**: free for personal, educational and commercial use, with no attribution required. The pack's own licence file is kept alongside the models as `KAYKIT_LICENSE.txt`.

Only the pieces the game uses are included here, as glTF files (`.gltf` + `.bin`) with the shared texture `furniturebits_texture.png`. They are unmodified; the game tints a few of them (the rugs) at runtime.

The people, walls, doors, signs, whiteboard, underwriting boxes, escalator and bell rostrum are built in code from simple shapes, so they have no model files.

three.js (MIT licence, see `../vendor/LICENSE`) is vendored at version 0.170.0 from its npm package: `three.module.min.js`, `GLTFLoader.js` and `BufferGeometryUtils.js`, unmodified.
